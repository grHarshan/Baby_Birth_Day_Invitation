Drop your baby photos here!

Formats supported: .jpg, .png, .webp, .svg

To use a photo in the app:
1. Save your image into this public/photos/ directory (e.g. hero.jpg, baby1.jpg).
2. Open lib/config.ts
3. Update the path:
   heroPhoto: "/photos/hero.jpg"
   story: [ { photo: "/photos/baby1.jpg", ... } ]
